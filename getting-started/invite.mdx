---
title: "Invite Percy"
description: "Add Percy to your Discord server and check that it answers."
---

You need the **Manage Server** permission on the server you want to add Percy to.

<Steps>
  <Step title="Open the invite link">
    [Invite Percy](https://discord.com/oauth2/authorize?client_id=1070054930125176923&scope=bot+applications.commands&permissions=8). You can also open the [dashboard](https://percy.klappstuhl.me/dashboard/), log in and click **Add Percy** next to a server you manage.
  </Step>
  <Step title="Pick your server">
    Choose the server in the drop-down and click **Authorize**. Solve the captcha if Discord asks.
  </Step>
  <Step title="Test it">
    In a channel Percy can see, run:

    ```text
    ?ping
    ```

    Percy answers with its latency.
  </Step>
</Steps>

<Note>
  The link above asks for the **Administrator** permission because it is the simplest setup. You can invite Percy with fewer permissions. See [Permissions Percy needs](/getting-started/permissions).
</Note>

<Tip>
  Run `?help` to browse every command. `?help <command>` shows the details for one.
</Tip>

## If Percy doesn't answer

- Check that Percy is online in the member list.
- Check that Percy can **View Channel** and **Send Messages** in that channel.
- Try `@Percy ping`. The mention works even if the prefix was changed.
- Still stuck? Read [Commands not working](/help/commands-not-working).
