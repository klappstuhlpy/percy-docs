## Playback

| Command | What it does |
|---|---|
| `/play <query or link>`, `/playsearch` | Queue a track, or pick from search results |
| `/toggle`, `/pause`, `/resume` | Pause or resume |
| `/forceskip`, `/back`, `/seek`, `/stop` | Skip, previous, jump to a position, stop |
| `/loop`, `/shuffle`, `/volume` | Loop mode, shuffle, volume |
| `/connect`, `/leave` | Join or leave voice |
| `/queue show`, `jump`, `move`, `remove` | View and edit the queue |
| `/filter bassboost`, `nightcore`, `lowpass`, `equalizer`, `reset` | Audio filters |
| `/discover foryou`, `history`, `artist <name>`, `album <link>` | Recommendations and history |
| `/music setup` | Create the player panel channel |
| `/music radios`, `/music 247 <mode>` | Radio stations; 24/7 mode (`radio`, `playlist`, `autoplay`, `off`) |
| `/vibe <description>` | AI: query and filter from a description |

Queue editing and filters require DJ mode permissions where DJ mode is on. 24/7 mode stops if an admin disconnects Percy manually.

## Playlists

| Command | What it does |
|---|---|
| `/playlist create`, `rename`, `delete`, `show` | Manage playlists |
| `/playlist add`, `remove`, `clear` | Edit tracks |
| `/playlist play`, `/playlist cover` | Queue a playlist; set cover image |

## Web player

[percy.klappstuhl.me/dashboard/music](https://percy.klappstuhl.me/dashboard/music); a green dot marks servers where Percy is playing.

<Frame>
  <img src="/images/home-13-dashboard-music.webp" alt="The dashboard music player" />
</Frame>

- **Home:** recently played, trending, picks from your top artists.
- **Player:** queue, lyrics, volume, loop, shuffle. Controls unlock once you are in Percy's voice channel.
- **Library:** liked songs and playlists, shared with the `/playlist` commands. Add songs from the **...** menu, the heart button, or by dragging onto a playlist.
- **Queue editing and sound** (equalizer, filters): DJs and members with Manage Server.
- **Session settings** (Manage Server): DJ mode and 24/7 mode.

Keys: `Space` play/pause, left/right seek, `M` mute, `/` search.
