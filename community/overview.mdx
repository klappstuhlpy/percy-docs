## Quick starts

| I want to | Do this |
|---|---|
| Start XP and level-up announcements | Open **Leveling** on the dashboard and use the one-step setup, or run `/level config toggle` |
| See my rank | `/level` |
| Change my rank card | `/level card` |
| Run a poll | `/polls create` |
| Start a giveaway | `/giveaway create` |

## On the dashboard

Under **Features** and **Community** in the sidebar you can set up leveling, polls, giveaways, tags, role menus and the starboard without commands. See [Dashboard and setup](/dashboard/overview).
