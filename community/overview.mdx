## Polls

| Command | What it does |
|---|---|
| `/polls create` | Create a poll (options, duration, optional banner) |
| `/polls edit`, `/polls end`, `/polls delete` | Change, close or remove a poll |
| `/polls search`, `/polls history` | Find past polls |
| `/polls config` | Server poll settings |
| `/polls ask <description>` | AI: build a poll from a description. See [AI](/ai/overview) |

## Giveaways

| Command | What it does |
|---|---|
| `/giveaway create` | Start a giveaway (prize, duration, winners) |
| `/giveaway end` | End one early and draw winners |
| `/giveaway quick <description>` | AI: build one from a description |

## Tags

Saved text snippets, called with `/tag <name>`.

| Command | What it does |
|---|---|
| `/tag create`, `/tag make` | Create a tag |
| `/tag edit`, `/tag delete`, `/tag alias` | Change, remove or alias a tag |
| `/tag info`, `/tag raw`, `/tag list`, `/tag stats` | Inspect tags |
| `/tag search <query>` | Search by name |
| `/tag find <question>` | AI: find a tag by meaning |
| `/tag claim`, `/tag transfer` | Take ownership of an orphaned tag; give one away |
| `/tag export`, `/tag purge` | Export all tags; remove a member's tags |

## Custom commands and aliases

Percy runs your own commands with typed arguments, flags, permissions, cooldowns and random responses. A bare `?cc` opens an interactive manager; the dashboard **Rules & Custom** page does the same.

| Command | What it does |
|---|---|
| `?cc create`, `edit`, `rename`, `delete` | Manage a custom command |
| `?cc addresponse`, `removeresponse` | Add or remove a random response |
| `?cc list`, `info`, `raw` | Inspect custom commands |
| `?alias add`, `remove`, `list` | Short names for existing commands |
| `?config rule allow|deny|remove|list` | Per-role, channel or member command permissions; `?config explain` shows which rule decided |

## Starboard

Messages that reach a reaction threshold are reposted to a channel.

| Command | What it does |
|---|---|
| `/starboard channel`, `emoji`, `threshold` | Where, which emoji, how many reactions |
| `/starboard toggle`, `selfstar`, `nsfw`, `maxage` | Enable; allow self-stars; allow NSFW; maximum message age |
| `/starboard ignore`, `/starboard top` | Exclude channels; top messages |

## Role menus

| Command | What it does |
|---|---|
| `/rolemenu create`, `/rolemenu delete` | Create or delete a menu |
| `/rolemenu add`, `/rolemenu remove` | Add or remove a role entry |
| `/rolemenu unique` | Allow only one role from the menu |

Percy's role must be above the roles in the menu.
