Members earn XP for messages (3+ characters, per-member cooldown, bots ignored) and for voice time (every minute with at least two humans present and the member not AFK or deafened). XP is per server. Role and channel multipliers and active boosts stack.

## Commands

| Command | What it does |
|---|---|
| `/level rank [member]` | Show a rank card |
| `/level card` | Edit your rank card (theme, accent, bar, font) with a live preview |
| `/level leaderboard` | Top 10 by XP |
| `/level set <target>` | Administrator: set XP or level with `--xp` / `--level` |
| `/level config` | Show configuration |

## Configuration

These need **Manage Server** and are also on the dashboard **Leveling** page.

| Command | What it does |
|---|---|
| `/level config toggle <true\|false>` | Enable or disable leveling |
| `/level config roles` | Level reward roles |
| `/level config message <text>` | Level-up message |
| `/level config channel [channel]` | Where level-ups post: a channel, the source channel, DMs or nowhere |
| `/level config ignore <entities>`, `unignore` | Roles, channels or users that earn no XP |
| `/level config multiplier` | XP multipliers per role or channel |
| `/level config voice <true\|false> [xp_per_minute]` | Voice XP and rate (1 to 1000) |
| `/level config delete-after-leave <true\|false>` | Delete XP when a member leaves |

Level-up message placeholders: `{user}`, `{user.mention}`, `{user.display_name}`, `{level}`.

The dashboard sets the server's default rank card style. **Lock style for everyone** forces it and hides the `/level card` editor.
