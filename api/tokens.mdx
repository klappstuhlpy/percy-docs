## Create a token

You need the **Manage Server** permission on the server.

<Steps>
  <Step title="Open Developers">
    Open the [dashboard](https://percy.klappstuhl.me/dashboard/), choose your server, then click **Developers** under **Integrations**.
  </Step>
  <Step title="Name it and pick scopes">
    Click **Create token**. Name it after what will use it. Tick only the scopes it needs.
  </Step>
  <Step title="Copy it now">
    Percy shows the token **once**. It starts with `pct_`. Percy keeps only a hash, so it can't show the token again. If you lose it, revoke it and make a new one.
  </Step>
</Steps>

<Warning>
  Never put a token in browser code, a public repository or a message. Keep it on your server in an environment variable.
</Warning>

## Scopes

A token can do nothing until you give it scopes.

| Scope | Allows |
|---|---|
| `economy:read` | Read balances and the richest-members list |
| `economy:write` | Change balances |
| `items:read` | Read the shop and member inventories |
| `items:write` | Create, edit and delete items. Give and take inventory |
| `leveling:read` | Read levels and the leveling leaderboard |
| `stats:read` | Reserved for statistics endpoints. It has no endpoints yet |

A request without the right scope returns `403 missing_scope` and tells you which scope it needed.

## Limits

- One server per token.
- Up to 10 active tokens per server.
- Revoking a token takes effect immediately.
- The Developers page shows when each token was created and last used.

See [Developers and API tokens](/dashboard/developers) for the dashboard side.
