## Reminders

Times are read in UTC unless you set a timezone.

| Command | What it does |
|---|---|
| `/reminder create <prompt> [flags]` | Create a reminder from natural language, e.g. `/reminder create submit the report in 2h`. Aliases: `/remindme`, `/remind`, `/timer`, `?remind` |
| `/reminder list` | Active reminders with IDs |
| `/reminder delete <id>` | Delete one |
| `/reminder purge` | Delete all |

## Personal settings

| Command | What it does |
|---|---|
| `/settings`, `/settings show` | Settings card: timezone and tracking toggles |
| `/settings timezone set <timezone>`, `show`, `info <timezone>`, `reset` | Timezone |
| `/settings request-data` | Export your data |
| `/settings remove-personal-data` | Erase your stored personal data |

Disabling a tracking toggle stops new collection; it does not delete existing data. See the [Privacy Policy](/legal/privacy-policy).

## Tools

| Command | What it does |
|---|---|
| `?shorten <url> [alias]` | Short link on `r.klappstuhl.me` |
| `?paste <content>` | Hosted snippet with a highlighted link |
| `?qr <data>`, `?preview <url>` | QR code; link preview metadata |
| `?image blur\|pixelate\|deepfry\|invert\|grayscale\|convert\|info\|palette` | Image tools |
| `?scan` | Scan an attachment for malware |
| `?screenshot <url>` | Render a public page to PNG |

## Autoresponders

Reply automatically when a message matches a trigger.

| Command | What it does |
|---|---|
| `/autoresponder add`, `remove`, `list`, `toggle` | Manage autoresponders (alias `/ar`) |

## Temporary voice channels

Joining a hub channel creates a personal voice channel for the member.

| Command | What it does |
|---|---|
| `/temp set <channel> [format]` | Make a channel a hub. Format placeholders: `%name`, `%display_name`, `%channel`, `%guild` |
| `/temp list`, `/temp remove <channel>`, `/temp purge` | List, remove one, remove all hubs |
