## Quick starts

| I want to | Do this |
|---|---|
| Be reminded of something | `/remind in 2h to submit the report` |
| Follow a series or a person | `/subscribe`. See [Release subscriptions](/utility/subscriptions) |
| Set my timezone | `/settings timezone set Europe/Berlin` |
| Export my data | `/settings request-data` |

<Tip>
  Percy reads reminders in your own timezone. Set it once with `/settings timezone set`.
</Tip>
