Percy is a Discord bot for moderation, a per-server economy, music, leveling and community tools. You run it with commands in Discord and manage it from a [web dashboard](https://percy.klappstuhl.me/dashboard/).

This guide is task-based. Each section starts with an overview, then short articles that tell you how to do one thing.

<Note>
  Not every command is a slash command. All commands work with the prefix (`?` by default, or `@Percy`). Many also work as slash commands. Type `/` in Discord to see which ones you get.
</Note>
