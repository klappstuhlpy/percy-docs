## Earn

| Command | What it does |
|---|---|
| `/daily`, `?weekly`, `?monthly` | Timed rewards; daily builds a streak |
| `?work` | Work a shift. `/job list`, `/job apply <name>`, `/job quit` |
| `?beg`, `?search`, `?fish`, `?hunt`, `?dig`, `?postmemes` | Activities with random rewards and item drops. `?fish`, `?hunt` and `?dig` pay 60% and find no items without the matching tool |
| `?crime` | Higher risk and reward |
| `/quests` | Daily quests |
| `?voteclaim` | Coins for voting on a bot list (`?vote`) |
| `?cooldowns`, `?multipliers` | Ready activities; active boosts |

## Manage money

| Command | What it does |
|---|---|
| `/economy` | Standing summary card |
| `/balance [member]`, `/balance leaderboard` | Cash and bank; server ranking |
| `/deposit <amount>`, `/withdraw <amount>` | Move coins (`all` and `half` accepted) |
| `/transfer <member> <amount>` | Send coins |
| `/rob <member>`, `/heist <member>` | Steal cash, alone or with a crew. `/passive` opts out both ways |
| `?prestige` | Reset wealth for a permanent payout bonus |
| `/pet adopt <species>`, `/pet feed`, `/pet claim` | A pet that earns while you are away |
| `/achievements`, `?collection`, `?profile [member]` | Badges, item drops, profile card |

## Items and shop

Items are bought, found, used, sold, gifted or traded. The shop and inventory are interactive cards. Rarity (Common to Legendary) is cosmetic. Percy's built-in items (tools and drops) cannot be edited; server items are managed by admins.

| Command | What it does |
|---|---|
| `/shop`, `/inventory [member]` | Open the shop or an inventory |
| `/item <name>` | Price, effect, stock |
| `/buy <item> [quantity]`, `/sell <item> [quantity]` | Buy; sell back for half the price |
| `/use <item> [quantity]` | Use an item |
| `/gift <member> <item> [quantity]`, `/trade <member>` | Give items; swap items and cash |
| `/perks [member]` | Active boosts |
| `/shop edit` | Admins: edit server items |

Editing an item changes it in place. Removing an item deletes every copy members own and asks for confirmation. The dashboard **Economy** page has the same item editor.

## Server settings

Admins use the dashboard **Economy** page or `?economy-config`:

| Command | What it does |
|---|---|
| `?economy-config multiplier <value>` | Payout multiplier |
| `?economy-config daily-base <amount>` | Base daily reward |
| `?economy-config rob <on/off>` | Allow robbing |
| `?economy-config max-bet <amount>` | Cap casino bets (`0` = no cap) |
| `?economy-config bank-cap <on/off>` | Limit bank size |
| `?economy-config drops <on/off>` | Random chat drops |
| `/economy set-money`, `/economy remove-money`, `/economy add-money-role` | Edit balances |
