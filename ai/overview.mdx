---
title: "AI"
description: "Optional AI features running on a self-hosted Ollama model."
---

The AI layer is optional, off by default and enabled per server on the dashboard **AI** tab, with per-channel overrides. If the model is disabled, unreachable or unsure, Percy uses the normal command instead. The model runs on Percy's own server; message text is not sent to a third-party AI provider or stored for training.

## Features

| Feature | Command | Fallback |
|---|---|---|
| Assistant | `?ask <question>`; replies thread into a conversation and may offer a button to run the recommended command | None |
| Command router | Natural-language messages mapped to a command, run only after confirmation | Normal commands |
| Polls | `/polls ask <description>` | `/polls create` |
| Giveaways | `/giveaway quick <description>` | `/giveaway create` |
| Music | `/vibe <description>` | `/play` |
| Tags | `/tag find <question>` | `/tag search` |
| Moderation flags | Posts an alert for review; never acts on its own | None |

## Moderation flags

A message is flagged only if the feature is on for the channel, the model is available, the author is not a bot, the owner or staff with Manage Messages, the author and channel are not on the AutoMod ignore list, the message is at least 16 characters, the verdict is harmful with confidence of at least 0.7, and the author has not triggered an alert in the last 15 seconds. Alerts go to the channel set with `/moderation alerts` or `/moderation auditlog`; a moderator can warn or kick from the alert (Kick Members required, recorded as a normal case).

## Self-hosting

| Variable | Purpose |
|---|---|
| `OLLAMA_ENABLED` | Master switch |
| `OLLAMA_HOST` | Ollama URL |
| `OLLAMA_FAST_MODEL` | Routing, tag find |
| `OLLAMA_BALANCED_MODEL` | Moderation, polls, giveaways, music |
| `OLLAMA_SMART_MODEL` | Assistant |
| `OLLAMA_TIMEOUT` | Per-call timeout (seconds) |
| `OLLAMA_MAX_CONCURRENCY` | Concurrent model calls |

User text is treated as data and cannot change the system instructions; the assistant does not reveal them.
