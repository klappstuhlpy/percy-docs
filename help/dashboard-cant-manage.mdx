---
title: "The dashboard says I can't manage my server"
description: "Fix a missing server, a server under Servers you're in, or an Add Percy button."
---

You can manage a server on the [dashboard](https://percy.klappstuhl.me/dashboard/) if you **own it** or have the **Manage Server** permission, and Percy is in it.

## Find your case

| What you see | What to do |
|---|---|
| The server is under **Add Percy** | Percy isn't in it yet. Click the button and [invite Percy](/getting-started/invite) |
| The server is under **Servers you're in** | You don't have Manage Server there. Ask an admin for the permission or for a role that has it |
| The server isn't listed at all | Log out and log in again. See below |
| A banner says some data couldn't be loaded | Percy was unreachable for a moment. Wait a minute, reload, and don't save until the pickers fill in |

## Refresh your server list

The dashboard reads your servers when you log in. If you just got Manage Server, or just joined:

<Steps>
  <Step title="Log out">
    Use **Log Out** in the dashboard.
  </Step>
  <Step title="Log in again">
    Approve the Discord prompt. It asks to see which servers you are in.
  </Step>
  <Step title="Open the server">
    It should now be under **Managed**.
  </Step>
</Steps>
