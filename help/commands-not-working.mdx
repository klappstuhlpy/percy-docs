---
title: "Commands not working"
description: "Work through this checklist when Percy doesn't answer or refuses a command."
---

Go through the list in order. Most problems are in the first four.

<Steps>
  <Step title="Is Percy online?">
    Check the member list. If Percy is offline, check the [Percy Support Server](https://discord.gg/3jSYQ9VNbA) for news.
  </Step>
  <Step title="Are you using the right prefix?">
    The default prefix is `?`. Your server may have changed it. The mention always works, so try:

    ```text
    @Percy ping
    ```

    To see the prefixes, run `@Percy prefix`.
  </Step>
  <Step title="Can Percy see and answer in this channel?">
    Percy needs **View Channel**, **Send Messages** and **Embed Links** in the channel. A channel-level deny beats a role grant. See [Permissions Percy needs](/getting-started/permissions).
  </Step>
  <Step title="Is the channel or your account ignored?">
    A moderator may have told Percy to ignore the channel or you. Administrators can always run commands. Ask a moderator to check:

    ```text
    ?config ignore list
    ```
  </Step>
  <Step title="Is the command disabled?">
    A command can be off in one channel or the whole server:

    ```text
    ?config disabled
    ```

    The **Commands** page of the dashboard shows the same. See [Command permissions](/dashboard/command-permissions).
  </Step>
  <Step title="Does the command need a permission?">
    Moderation and admin commands check your Discord permissions. A server can also change who may run a command. If Percy says you lack a permission, ask an admin or check the **Commands** page.
  </Step>
  <Step title="Are you on cooldown?">
    Earning commands have cooldowns. Percy tells you when you can use them again. `?work` waits an hour. See [Earning money](/earning/overview).
  </Step>
</Steps>

## Only works on a server

Most commands only work in a server, not in direct messages.

## Slash command or prefix?

Not every command is a slash command. If a command isn't in the `/` menu, use the prefix, for example `?fish`. See [Slash commands are missing](/help/slash-commands-missing).

## Still stuck?

Run `?permissions bot` to see what Percy can do in the channel, then look at the [setup status](/dashboard/setup-status) in the dashboard.
