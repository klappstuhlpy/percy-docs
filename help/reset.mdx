Find what you want to reset.

## Server settings

These need moderator or Manage Server permissions.

| To reset | Run |
|---|---|
| All prefixes. Only `@Percy` works afterwards, so add one back with `@Percy prefix add ?` | `?prefix reset` |
| Every ignored channel and member | `?config ignore clear` |
| Custom permission rules for a command | `?config perms reset <command>` |
| A disabled command | `?config server enable <command>` |
| Sentinel verification | Press **Stand Down** in the Sentinel menu. See [Sentinel](/moderation/sentinel) |
| The bot's profile on your server | **Custom Bot** tab, then **Reset**, on the dashboard |

## Music

| To reset | Run |
|---|---|
| All audio filters | `/filter reset` |
| A saved playlist's songs | `/playlist clear <playlist>` |
| The equalizer | **Reset** on the Music page of the dashboard |

## Economy

| To reset | How |
|---|---|
| One member's balance | `/economy set-money @member 0 cash`, and the same with `bank`. Needs Administrator |
| Your own job | `/job quit` |
| Your pet | `/pet abandon`. There is no refund |
| Your cash and bank, for a bonus | [Prestige](/earning/overview#prestige) |

<Note>
  There is no command that wipes the whole server economy. Edit balances per member, or per role with `/economy add-money-role`.
</Note>

## Just for you

| To reset | Run |
|---|---|
| Your timezone | `/settings timezone reset` |
| Your reminders | `/reminder purge` |
| Presence, name and avatar history | `/settings remove-personal-data`. See [Data and privacy](/help/data-privacy) |

<Warning>
  Removing personal data and removing a shop item can't be undone.
</Warning>
