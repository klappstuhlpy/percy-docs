Percy records a **case** for every moderation action. A case has a number, the member, the moderator, the action and a reason.

<Frame>
  <img src="/images/home-8-modlog.webp" alt="A moderation case posted to the moderation log channel" />
</Frame>

## What creates a case

- Commands like `/warn`, `/kick`, `?ban`, `/tempban`, `/mute` and `/tempmute`.
- The same actions taken from the dashboard.
- Automatic actions: raid and mention-spam bans, kicks and bans for bypassing Sentinel, and tempbans or tempmutes that end on their own. These are filed under Percy's name with the reason Percy acted on.
- The **Ban All Raiders** button and `?multiban`.

## Commands

| Command | What it does |
|---|---|
| `?cases <user>` | List a member's cases. Aliases: `warnings`, `history`, `modlogs` |
| `?case <number>` | Show one case |
| `?reason <number> <text>` | Change a case's reason. The log post updates too |
| `?delcase <number>` | Delete a case and its log post |
| `/warn <member> [reason]` | Warn a member and record it |

```text
?cases @member
?reason 12 Repeated spam after warning
```

<Note>
  Case numbers are never reused. Deleting the newest case doesn't give its number to the next one, so an old log post never points at the wrong case.
</Note>

## Post cases to a channel

Cases are always recorded. To also post each one in a channel:

```text
?modlog set #mod-log
```

`?modlog` shows the current channel. `?modlog disable` stops posting. Cases are still recorded. You can also set this up with [Set up logging](/dashboard/logging).

## On the dashboard

The **Members** page shows a member's case history, and **Notifications** lists the last 7 days of cases. You can export cases as CSV.
