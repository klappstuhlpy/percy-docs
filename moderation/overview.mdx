## Commands

Percy needs the same permission as the moderator to carry out an action.

| Command | What it does | Permission |
|---|---|---|
| `/kick` | Kick a member | Kick Members |
| `?ban` | Ban a member or user ID | Ban Members |
| `?multiban` | Ban several IDs | Ban Members, Kick Members |
| `/softban` | Ban and unban to remove recent messages | Kick Members |
| `/unban` | Revoke a ban | Ban Members |
| `/tempban` | Ban for a duration (`30m`, `2h`, `3d`) | Ban Members |
| `/mute`, `/unmute` | Add or remove the mute role (`?muterole` sets it) | Manage Roles |
| `/tempmute` | Timed mute | Manage Roles |
| `/warn <member> [reason]` | Warn and record | Kick Members |
| `/slowmode` | Channel slowmode (`0s` disables) | Manage Channels |
| `/purge` | Bulk delete with filters | Manage Messages |

You cannot act on yourself, Percy or the owner, and your top role must be above the target's (the owner is exempt). Bans and kicks also need Percy's top role above the target's. The dashboard applies the same rules. Banning, unbanning, muting or unmuting cancels the member's earlier timed action.

### Purge flags

`--user`, `--contains`, `--prefix`, `--suffix`, `--after <id>`, `--before <id>`, `--bot`, `--webhooks`, `--embeds`, `--files`, `--emoji`, `--reactions`, `--delete-pinned`, and `--require any|all` (default `all`). A purge with no filters asks for confirmation.

## Cases

<Frame>
  <img src="/images/home-8-modlog.webp" alt="A moderation case in the moderation log" />
</Frame>

Every moderation action, manual or automatic, creates a numbered case. Numbers are never reused.

| Command | What it does |
|---|---|
| `?cases <user>` | List a member's cases (aliases `warnings`, `history`, `modlogs`) |
| `?case <number>` | Show one case |
| `?reason <number> <text>` | Change a reason; the log post updates |
| `?delcase <number>` | Delete a case and its log post |
| `?modlog set <channel>`, `?modlog disable` | Post cases to a channel, or stop |

The dashboard **Members** page shows case history and can export cases as CSV.

## Action requests

<Frame>
  <img src="/images/home-9-request.webp" alt="An action request with Approve and Deny buttons" />
</Frame>

A member with a requester role (or **Manage Messages**) can request an action they cannot run themselves. Percy posts it with Approve and Deny buttons in the request channel; the action runs only if a moderator with the matching permission approves. The first decision wins, and nobody can decide their own request.

| Command | What it does |
|---|---|
| `/request create <action> <member> <reason> [duration]` | File a request |
| `/request list` | Your last 10 requests |
| `/request cancel <id>` | Withdraw a pending request |

Requestable actions: `kick`, `warn`, `ban`, `softban`, `mute`, `unmute`, `timeout`, `untimeout`. Not requestable: `purge`, `unban`. Pending requests expire after 24 hours; finished requests and notifications are removed after 90 days. Set the request channel and requester roles on the dashboard **Notifications** page.
