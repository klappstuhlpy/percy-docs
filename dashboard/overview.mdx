Log in at [percy.klappstuhl.me/dashboard](https://percy.klappstuhl.me/dashboard) with Discord. You can manage a server if you own it or have **Manage Server**. Changes apply immediately.

</Frame>

Settings have no Save buttons. A banner at the bottom saves or discards all pending changes at once. `Ctrl+K` opens a page switcher.

## Pages

| Page | Contents |
|---|---|
| Configuration | Server settings, logging, moderation, **Setup status** (checks that Percy can post and assign roles where configured) |
| Notifications | Problems needing attention, [action requests](/moderation/overview#action-requests), and a change log (setting names only, kept 90 days) |
| Members | Search, history, moderation actions |
| Commands | Enable or disable commands per server or channel, set who may use them, ignore channels or members |
| Analytics | Commands, failures, XP and new members over 24 hours to 1 year |
| Leveling, Economy, Music, Polls, Giveaways, Tags | One page per feature, same settings as the commands |
| Backup and Templates | Export and restore settings, autoresponders and tags (no channel or role IDs), or apply a shared template |
| Webhooks | Signed JSON to your own URL on events such as `member.join`, `level.up`, `moderation.case` |
| Developers | Create [API tokens](/api/introduction) (up to 10 per server) |

Every member can open **My Profile** on shared servers: level, rank card, economy, command history and data settings.

## Logging

**Configuration, Moderation, Quick setup: logging** sends the audit, moderation, message and voice logs and alerts to one channel; Percy can create a private `#percy-logs`. **Send test** posts a test message.

| Command | What it does |
|---|---|
| `/moderation auditlog <channel>` | Set the audit log channel |
| `/moderation auditlog alter <flag> <value>` | Choose which events are logged |
| `/modlog set <channel>` | Post moderation cases to a channel |

## Web music player

Open [percy.klappstuhl.me/dashboard/music](https://percy.klappstuhl.me/dashboard/music) and pick a server. See [Music](/music/overview#web-player).
